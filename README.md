## Hi, I'm Igor 👋

Fullstack developer focused on TypeScript, Rust, cloud, and agent-based systems. I build production services end-to-end — from infrastructure and APIs to the user-facing layer — and I enjoy the kind of work where the interesting part is the system design, not just the code.

These days most of my side projects are built with AI coding agents in a plan-driven loop: an architect agent writes ADRs and phased plans, a dev agent implements them, a fresh session reviews the result, and repo hooks enforce the rules mechanically.
